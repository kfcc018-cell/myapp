# 최악의 직장상사 월드컵

Python 3만 필요합니다. 별도 패키지 설치는 없습니다.

## 실행

이 폴더에서 실행하세요.

```sh
python server.py
```

브라우저에서 http://127.0.0.1:8000 을 여세요.
종료하려면 터미널에서 Ctrl+C를 누르세요.
HTML 파일을 직접 열면 후보 API에 연결되지 않으므로 서버를 통해 접속하세요.

## 구성

- index.html: 8강 → 4강 → 결승 → 결과, 다시 하기
- server.py: HTML 제공 및 GET /api/bosses 후보 조회

후보 문구는 server.py의 BOSSES에서 수정하세요. 후보 수는 8명으로 유지하세요.
결과는 저장하지 않습니다.
